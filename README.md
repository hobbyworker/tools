# tools

Small tools I use myself and write about on [hobbyworker.me](https://hobbyworker.me/). Each folder holds one tool and has its own README.

| Folder | What it does | Article |
|---|---|---|
| [`claude/`](claude/) | `remote-control.sh` keeps Claude Code Remote Control running in tmux, one server per folder, so you can use Claude Code on your computer from the Claude app or claude.ai/code | [A Claude Code Remote Control script](https://hobbyworker.me/en/dev/2026-10-05-claude-code-remote-control-script-1-setup-and-usage/) |
| [`hugo/`](hugo/) | `hugo-lc.sh` runs `hugo server` for several Hugo sites in the background, each on its own port, and turns them on and off by name | [A Hugo preview server script](https://hobbyworker.me/en/dev/2026-11-11-hugo-preview-server-script-1-setup-and-usage/) |
| [`macos/`](macos/) | `intel-leftovers.sh` lists everything on an Apple silicon Mac that still needs Rosetta 2 — plugins, drivers, launch items, command-line tools and Steam games, not just apps — before macOS 28 drops it | [Before macOS 28: a script that finds what still needs Rosetta](https://hobbyworker.me/en/dev/2026-11-10-find-what-needs-rosetta-before-macos-28/) |
